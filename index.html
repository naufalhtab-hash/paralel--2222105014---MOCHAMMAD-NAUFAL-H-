Parallel Computing · Monte Carlo

Estimasi Nilai π

Simulasi Monte Carlo menggunakan titik acak pada persegi satuan. Pekerjaan dibagi ke beberapa Web Worker, masing-masing memiliki generator angka acak sendiri.

Pengaturan simulasi

Maksimum sesuai tugas: 1.000.000.000 titik. Mulai dari 1–10 juta untuk menguji perangkat.
Worker berjalan paralel di browser. Pilih sesuai jumlah core CPU yang tersedia.
Siap. Atur sample dan jumlah worker, lalu mulai.

Semakin banyak sample, estimasi umumnya semakin stabil. Hasil setiap eksekusi dapat sedikit berbeda karena titik dibuat secara acak.
